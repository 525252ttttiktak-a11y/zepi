# Zepi

Голосовой ассистент для Android. Интерфейс: Jetpack Compose, тёмная тема, сфера-сетка, режимы БАЗА/ПРО, быстрые настройки, команды, настройки (Голос, Нейросеть, Дизайн, Информация).

## Сборка с телефона
1. Создай новый репозиторий на GitHub и загрузи туда все файлы этой папки.
2. Вкладка Actions, запусти «Build APK» (или просто сделай commit).
3. Скачай APK из Artifacts и установи.

## Куда подключать логику
В `MainActivity.kt`: `onSend(text)` (ответ нейросети) и `onMic(listening)` (распознавание речи).
